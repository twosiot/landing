# Twosiot Landing

Simple static landing page for Twosiot.

## Local Preview

Open `index.html` in a browser, or run any small static server from this
directory.

## GitHub Pages

1. Push this folder to a public GitHub repository.
2. In GitHub, open `Settings -> Pages`.
3. Choose `Deploy from a branch`, then `main` and `/root`.
4. Add the custom domain when ready.

For a root/apex domain on GitHub Pages, create GitHub's `A` records at the DNS
provider. For `www`, create a `CNAME` pointing to the GitHub Pages hostname.
